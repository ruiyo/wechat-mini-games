# 词弹碰碰局

**V0.8 · Cocos Creator 3.8.8 · 微信小游戏**

《词弹碰碰局》是一款融合汉字组词、弹药构筑和物理弹射的轻策略休闲小游戏。

## 核心玩法（V0.8）

**组词造弹 → 瞄准击碎汉字块 → 收集新字 → 弹药碰撞融合 → 连锁得分 → 清关三选一强化 → 挑战字王。**

新玩家从主菜单「汉字冒险」进入四关短局；每关有发射次数限制和一组具有耐久度的汉字块，清空所有字块即过关。最后一关包含五点耐久的「王」字块。每次击破普通字块，该字会收入奖励队列，玩家下次确认组词时优先补入字池，并自动搭配可组成词语的汉字。每关结束后选择三项强化中的一项，增强后续弹药或连锁伤害。

**弹间融合：** 两种不同类型弹药实际碰撞时触发六种组合技，造成可见的物理效果和范围碎字冲击；同一弹药对每一发最多融合一次，以避免重复触发刷分。

**四个入口：** 「汉字冒险」为默认主玩法；「经典无尽」保留原目标圈刷分与五次失误结束；「碰撞练习」可直接选弹；「每日挑战」以 UTC 日期固定关卡布局、抽字顺序及升级选项，并将每日最高成绩保存在本机（无联网好友榜）。

## V0.8 六种融合技

| 弹药碰撞组合 | 融合名称 | 主要效果 |
|---|---|---|
| 磁吸 + 冰冻 | 冰磁陷阱 | 牵引并冻结附近弹药，冻结冲击可破坏字块 |
| 磁吸 + 冲击 | 引力爆弹 | 释放较大范围的击退波 |
| 弹跳 + 冰冻 | 冰晶连弹 | 寒霜波及附近弹药和汉字块 |
| 弹跳 + 冲击 | 震荡弹 | 释放高伤害碎字震荡波 |
| 冰冻 + 冲击 | 破冰弹 | 解除附近冰冻后释放冲击 |
| 弹跳 + 磁吸 | 回旋磁弹 | 触发短暂加强的持续吸附场 |

## V0.7 碰撞练习

新增主菜单「碰撞练习」：场上预放两颗不同弹药供击打，直接在底部选择「弹跳 / 磁吸 / 冰冻 / 冲击」试射，无需重复组词。每次练习有撞击次数和碰撞动画，练习不受 5 次失误限制，**不会更新历史最高分或收录图鉴**。通过右上角暂停可重新开始或返回主菜单。

游戏主线仍是正常的组词 → 制弹 → 发射 → 得分；练习模式与其隔离。新增 Node 级伪 Cocos 运行环境下的碰撞生命周期及力学响应自动测试，可以执行真实的 PuckInteractionSystem 而非只匹配源码。

## 当前版本

- 24 个双字词，映射 4 种弹药。
- 720×1280 竖屏布局，按高度适配。
- 真实 2D 刚体接触事件：弹药相撞会更新撞击计数，产生冲击波与对应弹种反馈。
- 实战以外增加可无限练习的碰撞试验模式，用固定演示弹药直观比较四种效果。
- **弹跳**：提高弹性（墙壁和旧弹药碰撞都会弹开）。
- **磁吸**：发射后最多持续 3.2 秒，磁场半径 235，可唤醒并牵引静止的旧弹药；磁吸弹自身停住也能继续吸引，显示牵引线。
- **冰冻**：撞击或停下后产生半径 108 的寒霜区域，范围内旧弹药会变为 Static 刚体，在约 2.4 秒内完全无法被撞动，结束后恢复 Dynamic。
- **冲击**：增加质量并在真实接触后向旧弹药额外传递速度冲量。
- 精细力度控制、高对比度轨迹与碰撞候选高亮（最多预览两次墙面反弹）。
- 组词「提示」按钮（仅选词、不自动消耗字卡）。
- 主菜单、玩法说明、暂停与结算页。
- 发射阶段收起整个组词面板，避免遮挡操作区域。
- 连击倍率、失误限制、最高分和词语图鉴。
- 本局发现词语独立计数，跨局图鉴本地保存，可从组词界面的「图鉴」按钮查看 24 个词语的收集状态。
- GitHub Actions 自动运行逻辑测试并调用 Windows Runner 构建微信小游戏。

- PuckBattleBootstrap：场景、UI、状态机和无尽循环。
- WordDictionary：本地双字词映射。
- WordPuzzleController：字池、选择、消耗和补字。

- FusionRules：六种无序弹药组合配方与连锁积分公式。
- ArcadeProgression：固定随机种子的四关布局、字王关卡、发射预算及九种升级。
- WordPuzzleController：奖励字待补队列与每日挑战确定性字池。
- SaveManager：每日离线最高分和原有持久化。
- ScoreRules：目标圈计分。
- SaveManager：最高分和词语图鉴本地存档。

## V0.7.2 特殊弹药实效修复

早期磁吸弹的牵引功能受到速度阈值和过早结算的限制，冰冻弹只提高阻尼，没有物理锁定。现已重新设计：

- **磁力场**：参考物理弹球游戏的范围磁场和持续施力思路，在可见范围内把旧弹药吸向磁吸弹；不要求磁吸弹持续高速运动。为了让玩家看见移动，存在可吸附目标时，结算会等待磁场持续时间结束。
- **寒霜场**：冰冻弹击中旧弹药或落地减速时，以当前位置释放一次范围寒霜。受影响弹药切换成 Cocos Box2D 的 Static 刚体，停住且不会被其他弹药推开，到时恢复 Dynamic。效果即使进入下一次组词阶段也保持，暂停期间不会提前失效。
- **反馈**：磁吸范围圈、指向弹药的蓝色牵引线、寒霜范围圈、冻结弹药上的冰晶符号、文字提示。冲击弹无法推动仍在冰冻中的弹药。
- **验证**：新增实际调用游戏状态机与碰撞系统的磁吸/冰冻测试。自动化测试使用精简 Cocos mock，不能替代微信开发者工具或手机上的真实 Box2D 操作验证。

## V0.6 使用说明

按住圆盘向后拖动，观察力度百分比和彩色方向预览，松手发射。预览仅估计墙壁反弹，**不预测障碍物、旧弹药或特殊弹种效果**，末端不是准确落点。组词困难时可点击「提示」。当方向引导线可能碰到旧弹药时，旧弹药周围显示红圈；只有真实物理接触发生后，才出现弹种撞击反馈并增加「撞击」次数。

## 快速开始

1. 使用 Cocos Creator 3.8.8 导入本目录。
2. 打开 assets/scenes/Game.scene。
3. 点击 Preview 运行。

## 黑屏修复与渲染层

所有运行时创建的背景、目标圈、文字、按钮和弹药节点，通过 `makeRenderNode()` 显式继承 Canvas 所在渲染层。Cocos Creator 新建节点默认位于 `DEFAULT` 层，而本工程 UI Camera 仅渲染 Canvas 层，因此不设置会造成微信小游戏 FPS 正常但整个画面黑屏。新增 `tests/logic/ui-render-layer.test.ts` 防止直接 `new Node()` 导致回归。
