# 词弹碰碰局

**V0.6 · Cocos Creator 3.8.8 · 微信小游戏**

《词弹碰碰局》是一款融合汉字组词、弹药构筑和物理弹射的轻策略休闲小游戏。

## 核心玩法

组词 -> 制弹 -> 发射 -> 碰撞 -> 得分 -> 再组词。

玩家从 6 个汉字中选择两个组成双字词。有效词语映射为弹跳、磁吸、冰冻或冲击弹。无尽模式不限制发射次数，连续失误达到 5 次后结束本局。场上最多保留 3 颗弹药，后续弹药可以推动旧弹药并改变其得分。

## 当前版本

- 24 个双字词，映射 4 种弹药。
- 720×1280 竖屏布局，按高度适配。
- 真实 2D 刚体接触事件：弹药相撞会更新撞击计数，产生冲击波与对应弹种反馈。
- **弹跳**：提高弹性（墙壁和旧弹药碰撞都会弹开）。
- **磁吸**：飞行方向偏转、吸引半径 150 内已有弹药，显示蓝色磁场。
- **冰冻**：靠近靶圈急停，撞击旧弹药后使其减速并冰冻约 1.2 秒。
- **冲击**：增加质量并在真实接触后向旧弹药额外传递速度冲量。
- 精细力度控制、高对比度轨迹与碰撞候选高亮（最多预览两次墙面反弹）。
- 组词「提示」按钮（仅选词、不自动消耗字卡）。
- 主菜单、玩法说明、暂停与结算页。
- 发射阶段收起整个组词面板，避免遮挡操作区域。
- 连击倍率、失误限制、最高分和词语图鉴。
- 本局发现词语独立计数，跨局图鉴本地保存，可从组词界面的「图鉴」按钮查看 24 个词语的收集状态。
- GitHub Actions 自动运行逻辑测试并调用 Windows Runner 构建微信小游戏。

## 代码模块

- PuckBattleBootstrap：场景、UI、状态机和无尽循环。
- WordDictionary：本地双字词映射。
- WordPuzzleController：字池、选择、消耗和补字。
- AmmoFactory：词语到弹药配置的映射。
- AmmoEffectController：弹药物理属性和飞行期效果。
- PuckInteractionRules：弹间接触、冲击与磁场的纯数学规则。
- PuckInteractionSystem：Box2D 碰撞监听、接触后特殊效果、磁场与可视化反馈。
- ScoreRules：目标圈计分。
- SaveManager：最高分和词语图鉴本地存档。

## V0.6.1 修复说明

修复首次开始/重新开始时碰撞系统重置触发的 `Cannot read properties of undefined (reading 'off')`。
移除不兼容的 `Map.values()` 遍历，使用稳定顺序的碰撞体数组；清理时检查回调可用性，重复注册和重复清理不会异常。
磁场、冰冻和撞击反馈的对象遍历同样使用兼容方式。
新增对应的初始化、重置及重复清理单元测试。请以最新完成的构建重新导入微信开发者工具。

## V0.6 使用说明

按住圆盘向后拖动，观察力度百分比和彩色方向预览，松手发射。预览仅估计墙壁反弹，**不预测障碍物、旧弹药或特殊弹种效果**，末端不是准确落点。组词困难时可点击「提示」。当方向引导线可能碰到旧弹药时，旧弹药周围显示红圈；只有真实物理接触发生后，才出现弹种撞击反馈并增加「撞击」次数。

## 快速开始

1. 使用 Cocos Creator 3.8.8 导入本目录。
2. 打开 assets/scenes/Game.scene。
3. 点击 Preview 运行。

入口场景和 Box2D 模块配置已经提交，不需要手动创建场景或挂载组件。

## 微信小游戏构建

GitHub Actions 会在可信分支 Push 后自动执行：

1. 项目结构和逻辑单元测试。
2. Windows Runner 调用 Cocos Creator 3.8.8。
3. 构建微信小游戏并验证竖屏配置、入口脚本和场景 UUID。
4. 分开上传 `word-puck-ready-to-play`（可直接导入）和 `word-puck-build-logs`（诊断日志）。

当前生成包使用 Cocos 默认测试 AppID。正式发布前必须替换为对应小程序的正式 AppID，并在微信开发者工具中完成预览和真机验收。

## 黑屏修复与渲染层

所有运行时创建的背景、目标圈、文字、按钮和弹药节点，通过 `makeRenderNode()` 显式继承 Canvas 所在渲染层。Cocos Creator 新建节点默认位于 `DEFAULT` 层，而本工程 UI Camera 仅渲染 Canvas 层，因此不设置会造成微信小游戏 FPS 正常但整个画面黑屏。新增 `tests/logic/ui-render-layer.test.ts` 防止直接 `new Node()` 导致回归。
