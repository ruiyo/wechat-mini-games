# 《词弹碰碰局》MVP 开发计划

## 产品目标

将原《冰壶碰碰局》三投计分原型改造为《词弹碰碰局》无尽模式。核心循环为：组词 -> 制弹 -> 发射 -> 碰撞 -> 得分 -> 再组词。

当前版本：V0.3
引擎：Cocos Creator 3.8.8
目标平台：微信小游戏
设计分辨率：720×1280，竖屏，按高度适配

- [x] 新增 WordDictionary.ts。

- [x] 提供 6 个汉字卡片 UI。
- [x] 支持选择/取消两个汉字。
- [x] 支持正序和逆序词语匹配。
