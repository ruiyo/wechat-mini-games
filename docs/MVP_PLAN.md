# 开发计划与 MVP 验收

## 目标

优先交付《冰壶碰碰局》可运行原型 V0.1。先证明拖动发射、圆盘碰撞和三投计分本身有趣，再决定是否扩展关卡和第二款游戏。

## Milestone 0：仓库与工程准备

- [x] 检查 GitHub 仓库权限和默认分支。
- [x] 建立 `feature/puck-battle-prototype` 分支。
- [x] 提交 GDD、技术设计和 MVP 文档。
- [ ] 在本地安装并确认 Cocos Creator 3.8 LTS。
- [ ] 创建 Cocos Creator 项目并放入 `games/puck-battle/`。
- [ ] 提交项目工程骨架和资源目录。

## Milestone 1：最小物理原型

### 任务

- [ ] 创建竖屏游戏场景。
- [ ] 创建矩形场地和静态边界。
- [ ] 创建圆盘预制体（Dynamic RigidBody2D + CircleCollider2D）。
- [ ] 配置零重力和固定时间步长。
- [ ] 实现单颗圆盘发射。
- [ ] 实现圆盘与边界碰撞。
- [ ] 实现圆盘与圆盘碰撞。
- [ ] 调整速度衰减和停止效果。

### 验收

- 圆盘能够从发射区滑向目标区。
- 圆盘撞墙后不会穿透边界。
- 两颗圆盘碰撞后能够互相推动。
- 圆盘能够自然减速并稳定停止。
- 不出现明显抖动、穿透或永久运动。

## Milestone 2：操作与三投循环

### 任务

- [ ] 实现触摸按下、拖动和松开。
- [ ] 实现瞄准线和力度提示。
- [ ] 实现最大/最小拖动距离限制。
- [ ] 实现三次投掷状态机。
- [ ] 实现多个发射点和占用检测。
- [ ] 等待所有圆盘稳定后再进入下一投。

### 验收

- 玩家可以单指完成瞄准和发射。
- 拖动距离与力度变化一致。
- 运动过程中不能重复发射。
- 每局准确提供三次投掷。
- 后续投掷能够推动之前的圆盘。

## Milestone 3：计分与完整游戏流程

### 任务

- [ ] 创建三层目标区。
- [ ] 根据最终位置计算每颗圆盘得分。
- [ ] 每次碰撞后重新计算暂定分数。
- [ ] 创建主菜单、HUD 和结算界面。
- [ ] 实现再玩一次。
- [ ] 保存个人最高分。

### 验收

- 三次投掷完成后才结算。
- 所有圆盘分数与最终位置一致。
- 最高分保存正确。
- 重新开始不会残留上一局圆盘或状态。

## Milestone 4：体验打磨和微信适配

### 任务

- [ ] 添加简单碰撞音效和视觉反馈。
- [ ] 调整圆盘颜色、目标圈和操作提示。
- [ ] 检查竖屏和安全区域。
- [ ] 构建微信小游戏。
- [ ] 使用微信开发者工具进行模拟器测试。
- [ ] 至少在一台真实手机上测试触摸与物理表现。
- [ ] 记录问题并修复。

### 验收

- 从主菜单到结算可以完整运行。
- 微信开发者工具不出现阻断性错误。
- 触摸操作无明显偏移。
- 连续游玩多局没有状态残留。
- 本地最高分能够正确保存。

## 原型试玩指标

首轮邀请 10～20 名未参与开发的玩家试玩，记录：
- 是否在 30 秒内理解操作。
- 是否能独立完成三次投掷。
- 是否主动尝试撞击已有圆盘。
- 是否愿意连续再玩三局。
- 是否认为力度控制可预测。

建议内部目标：
- 首局完成率 ≥ 90%。
- 连续玩三局比例 ≥ 50%。
- 不出现阻断性物理/状态错误。

这些是项目内部的验证目标，不代表行业基准。

## 后续版本（不属于 V0.1）

- 固定布局挑战关卡。
- 不同场地材质。
- 特殊圆盘。
- 简单 AI 对手。
- 好友成绩分享。
- 异步挑战。

实时联机、付费、广告和服务器均不进入首版范围。
