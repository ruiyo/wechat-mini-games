# 《词弹碰碰局》MVP 开发计划

## 产品目标

将原《冰壶碰碰局》三投计分原型改造为《词弹碰碰局》无尽模式。核心循环为：组词 -> 制弹 -> 发射 -> 碰撞 -> 得分 -> 再组词。

当前版本：V0.4
引擎：Cocos Creator 3.8.8
目标平台：微信小游戏
设计分辨率：720×1280，竖屏，按高度适配

## V0.4 体验验收要点

首次启动应出现主菜单，不应直接进入组词界面。点击开始游戏后才进入首局；暂停期间物理世界停止，点击继续后恢复；结算页必须通过独立按钮重新开始或回主页。拖拽时箭头跟随手指，轻微移动不发射，中间力度可以精细控制。检查刘海屏顶栏、底部安全区和按钮覆盖问题。

**注意**：自动测试和引擎构建不等于设备交互验收，实际响应延迟和物理手感仍以微信开发者工具及真机为准。
