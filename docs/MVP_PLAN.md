# 《词弹碰碰局》MVP 开发计划

## 产品目标

将原《冰壶碰碰局》三投计分原型改造为《词弹碰碰局》无尽模式。核心循环为：组词 -> 制弹 -> 发射 -> 碰撞 -> 得分 -> 再组词。

## Milestone 1：组词系统

- [ ] 新增 WordDictionary.ts。
- [ ] 新增 WordPuzzleController.ts。
- [ ] 提供 6 个汉字卡片 UI。
- [ ] 支持选择/取消两个汉字。
- [ ] 支持正序和逆序词语匹配。
- [ ] 组词失败不消耗字。
- [ ] 组词成功消耗两个字并补充新词的两个字。
- [ ] 保证每次补字后至少存在一个有效词语。

验收：
- 首始字池至少包含三个可识别词语。
- 任意有效组词后字池保持 6 个汉字。
- 每次字池更新至少包含一个有效词语。

## Milestone 2：弹药工厂与效果

- [ ] 新增 AmmoFactory.ts。
- [ ] 新增 AmmoEffectController.ts。
- [ ] 实现弹跳弹。
- [ ] 实现磁吸弹。
- [ ] 实现冰冻弹。
- [ ] 实现冲击弹。
- [ ] 弹药外观展示对应词语。
- [ ] 弹药生成后进入瞄准状态。

验收：
- 四种弹药有明显可区分的物理表现。
- 发射速度和碰撞参数从弹药配置读取。
- 不同词语能正确映射到弹药类型。

## Milestone 3：无尽模式循环

- [ ] 移除固定三次投掷结束逻辑。
- [ ] 每次弹药停止后结算并进入下一次组词。
- [ ] 保留最近 3 颗弹药，允许后续碰撞推动旧弹药。
- [ ] 超过上限时移除最旧弹药并归档其得分。
- [ ] 每次稳定后重新计算活动弹药分数。
- [ ] 增加连击倍率。
- [ ] 增加 5 次失误结束机制。
- [ ] 增加总分、发射次数、连击和失误 HUD。

验收：
- 发射次数不受固定三次限制。
- 活动弹药数量最多为 3。
- 旧弹药分数归档不重复。
- 连击和失误值变化正确。
- 达到失误上限后进入结果界面。

## Milestone 4：图鉴、存档与体验打磨

- [ ] 保存最高分。
- [ ] 保存已发现词语。
- [ ] 显示本局发现词语数量。
- [ ] 结算界面展示分数、发射次数和发现词语。
- [ ] 重新开始清空本局状态。
- [ ] 调整组词和弹射界面布局。
- [ ] 微信开发者工具构建和触摸验证。

验收：
- 退出重进后最高分和词语记录保留。
- 重新开始后无上一局残留对象。
- 组词和发射循环可以连续运行。

## 原型验证目标

邀请 10～20 名未参与开发的玩家试玩，观察：
- 能否在 30 秒内理解组词和发射。
- 是否愿意尝试不同词语以获得不同弹药。
- 是否会根据当前场地选择弹药。
- 是否愿意连续玩 5 分钟。
- 是否觉得四种弹药效果有差异。

这些是内部产品验证目标，不是行业基准。

## 暂缓功能

- 多字词、成语和自由输入。
- 高级词语合成。
- 每日挑战和在线排行榜。
- 实时多人对战。
- 商城、广告、付费。
- 复杂成长系统。
