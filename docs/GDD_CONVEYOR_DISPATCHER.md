# 《传送带调度员》游戏设计概要

- 状态：候选第二项目
- 开发顺序：在《冰壶碰碰局》原型验证后再启动
- 类型：动态路线调度 / 轻度益智
- 目标平台：微信小游戏
- 美术：明亮可爱、2D 卡通

## 1. 核心概念

货物持续沿传送带移动，玩家通过点击分流开关，实时改变货物路线，让货物进入正确出口。

核心操作只有点击分流器切换方向。玩家需要观察货物类型、移动速度和到达分流器的时间，在货物通过前作出决定。

## 2. MVP 规则

- 一个入口。
- 一条主传送带。
- 一个左右分流器。
- 两条分支路线。
- 两个目标出口。
- 三种货物类型。
- 货物自动沿预设路径移动。
- 货物通过分流器时锁定当前路线，之后切换开关不影响已经通过的货物。
- 正确运输得分，错误运输扣除容错次数。
- 首版采用 45 秒挑战模式或固定货物序列关卡。

## 3. 初始配置

| 参数 | 初始值 |
|---|---:|
| 单局时长 | 45 秒 |
| 初始货物间隔 | 2.5 秒 |
| 初始移动速度 | 180 逻辑像素/秒 |
| 容错次数 | 3 |
| 分支路线 | 2 |
| 分流器 | 1 |

以上数值是原型调试起点。

## 4. 后续扩展

- 第二个分流器。
- 易碎品、重型货物、定时货物。
- 缓冲区和加工站。
- 多入口、多出口。
- 无限挑战模式。

## 5. 技术方案

不需要 Box2D。货物沿配置好的路径节点移动，使用路径进度和状态机控制。

建议模块：
- CargoSpawner：生成货物。
- CargoController：管理货物状态和移动。
- SwitchController：读取玩家切换操作。
- RouteController：计算路径和分流结果。
- ScoreController：计算正确运输数量和错误次数。
- GameManager：管理倒计时和结束状态。

该项目与《冰壶碰碰局》共用 UI、存档和基础配置工具，但不共用核心玩法代码。
