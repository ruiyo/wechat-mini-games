# 《冰壶碰碰局》游戏设计文档（GDD）

- 版本：0.1
- 状态：原型设计已确定
- 优先级：第一开发项目
- 目标平台：微信小游戏
- 画面：竖屏 2D 俯视、明亮可爱卡通风格

## 1. 产品定位

《冰壶碰碰局》是一款单人、短局、物理碰撞型休闲竞技小游戏。玩家通过拖动圆盘控制发射方向和力度，在每局三次投掷中争取更高分数，并利用后续圆盘撞击、推动之前的圆盘，改变最终得分。

核心卖点不是复杂规则，而是容易理解的拖动操作、清晰的力度反馈，以及圆盘之间可预期又有趣的碰撞。

## 2. 核心循环

1. 进入一局三投挑战。
2. 拖动当前圆盘，观察方向和力度预览。
3. 松手发射。
4. 等待场上所有圆盘稳定。
5. 记录本次投掷，生成下一颗圆盘。
6. 第三次投掷结束后，重新计算所有圆盘最终位置并结算。

**重要规则：** 已经投出的圆盘不会在下一投开始时消失。后续圆盘可以撞击并推动之前的圆盘，因此每次投掷都可能改变已有得分。

## 3. 核心操作

- 玩家按住当前圆盘并向后拖动。
- 拖动方向的反方向为发射方向。
- 拖动距离决定初始速度，达到最大拖动距离后不再增加力度。
- 松手发射。
- 拖动距离低于最小阈值时取消发射。
- 瞄准线显示方向和大致力度；原型阶段不要求精确预测所有碰撞后的轨迹。

## 4. 每局规则

- 每局固定三次投掷。
- 场上最多保留三颗玩家圆盘。
- 每次投掷必须等待所有圆盘稳定后才能开始下一投。
- 三次投掷全部完成后统一结算。
- 圆盘不得穿过场地边界；边界碰撞会使圆盘反弹或停止。
- 首版不加入对手圆盘，避免同时引入复杂对抗规则。

## 5. 目标区与计分

目标区位于场地远端，由三个同心圆组成。以目标中心到圆盘中心的距离判定得分：

| 区域 | 初始分值 |
|---|---:|
| 中心圈 | 50 |
| 中间圈 | 30 |
| 外围圈 | 10 |
| 目标区外 | 0 |

- 每颗圆盘最多获得一个区域分值。
- 总分为所有圆盘最终分值之和，基础上限为 150 分。
- 每次圆盘稳定后可以显示暂定分数；下一次碰撞后必须重新计算。
- 最终成绩只以第三投结束后的最终位置为准。

具体半径不写死在代码中，放入场地配置文件，并根据逻辑分辨率统一缩放。

## 6. 场地与视觉

首版使用一张固定场地：

- 竖屏 9:16。
- 底部为发射区域。
- 上方为三层同心目标区。
- 左右两侧和顶部设置边界。
- 使用明亮、干净的卡通冰面或桌面视觉。
- 圆盘采用高对比度颜色，确保运动过程中容易辨认。

第一版不做复杂场地装饰、动态障碍和多种材质。

## 7. 游戏模式

### 7.1 三投计分（MVP）

每局三次投掷，累计最终得分，刷新个人最高纪录。

### 7.2 固定布局挑战（MVP 后续）

使用固定目标位置或少量固定障碍，完成指定分数或碰撞目标。

### 7.3 好友/实时对战（暂不开发）

后续再评估异步成绩分享或轮流投掷。首版不接入实时联机和服务器。

## 8. 首版范围

### 必须实现

- 单一场地。
- 单一圆盘类型。
- 拖动瞄准和发射。
- 圆盘与边界、圆盘与圆盘之间的物理碰撞。
- 三次投掷管理。
- 圆盘停止检测。
- 目标区计分。
- 结算界面。
- 本地最高分保存。
- 微信小游戏构建与基础测试。

### 暂不实现

- 实时多人对战。
- AI 对手。
- 复杂关卡编辑器。
- 多种圆盘属性和技能。
- 商城、付费、广告。
- 账号、云存档和服务器。
- 排行榜。

## 9. 首轮体验验收目标

这些是内部原型目标，不是市场基准：

- 新玩家 30 秒内理解拖动发射。
- 玩家能够完成完整三投。
- 玩家能观察到圆盘碰撞并推动其他圆盘。
- 三投结束后的分数与最终位置一致。
- 连续试玩时不会出现圆盘无法停止或下一投提前出现。
- 退出并重新进入后，个人最高分仍然存在。
